
# Happy Mwalwanda - Personal Portfolio Website

## About the Project

This is my personal portfolio website developed as part of my
Multimedia Tools and Their Application assignment.

The website introduces my background, education, technical skills,
career interests and software development projects.

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Visual Studio Code
- Git and GitHub
- GitHub Pages

## Website Sections

1. Home - Introduction and personal profile.
2. About Me - Education, skills, hobbies and career aspirations.
3. Projects - Software development projects.
4. Animated Concepts - Demonstrations of CSS animations and effects.

## Main Features

- Black and green user interface.
- Responsive design for different screen sizes.
- CSS hover transitions.
- Typing text animation.
- Scroll reveal animation.
- Animated elements using CSS keyframes.
- Navigation between website pages.

## How to Run the Website

1. Download or clone the repository.
2. Open the project folder in Visual Studio Code.
3. Open index.html using a browser or Live Server.
